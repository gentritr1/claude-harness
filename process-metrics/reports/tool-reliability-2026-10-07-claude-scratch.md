## 1. Method
- Source: every `*.jsonl` transcript under `~/.claude/projects/` (main sessions and `subagents/`), scope: projects claude-scratch. Files are streamed line by line by `harness-audit` (`~/.claude/process-metrics/bin/`); only digests (tool name, category, timings, hashes, program names, redacted <=120-char error signatures) are kept. No prompt text, file content or command text is stored.
- A **call** is a `tool_use` block paired with its `tool_result` by id. Latency = result timestamp - use timestamp (ms resolution; includes permission/classifier latency). Background Bash calls are excluded from latency and hours (their launch returns at once).
- **Failure** = `is_error` on the result, or a timeout (timeout text, `timedOutAfterMs`, or a foreground command "moved to the background" at its limit). Each failure gets one cause class from the result text (first match wins; rules in `harness_core.classify_error`) and one bucket: **ENV** (host, shell setup, sandbox, permissions, services), **TOOL** (a different tool or shell form avoids it), **BEHAVIOUR** (the agent's own step was wrong), **SIGNAL** (the command worked and reported a real failure: failing test, tsc error, grep no-match).
- **Hours lost** per failure = failed call time + the reaction gap to the agent's next tool call, capped at 600 s (longer gaps are dormancy or owner time). It is an estimate of the turn spent on the failure, not a measured counterfactual.
- `permission:user-rejected` latency is the owner's decision time, so it is excluded from hours lost (0.0 h of owner time).
- Timeouts of a command whose identical skeleton later succeeded in the same agent are re-labelled `timeout:host-load-passed-on-rerun` (0 calls).
- Tool-choice comparisons report raw rates with Wilson 95% CIs and a **within-agent** Mantel-Haenszel odds ratio (strata = agents that used both arms), which removes between-task mix but not within-task mix. A difference "counts" only when the within-agent CI excludes 1.
- Concurrency: a minute is active for a project when any of its transcripts has an assistant/user record in it. Associations only.
