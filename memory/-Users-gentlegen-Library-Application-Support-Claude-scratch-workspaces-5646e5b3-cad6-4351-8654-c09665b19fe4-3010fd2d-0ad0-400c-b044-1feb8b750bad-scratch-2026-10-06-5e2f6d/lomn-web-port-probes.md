- TheLegendOfMataNui repos have NO engine source; game = original Win32 D3D8 `LEGOBionicle.exe` (Saffire SAGE, 2001-10-22) + ~1.1 GB data. Logic lives in exe; 419 LSS scripts only do puzzles/UI/cutscenes.
- exe has embedded CodeView NB11 (2.17 MB @ file 0x3d2200): 7,057 public names, 505 classes (160 Gc*), 37 line-table modules, 580 procs with locals (66 modules: bosses, AI, BKD anim, OSI ext), ~4.8k class type records.

- Gaps in type export: LF_INDEX continuations skipped (e.g. GcCollisionCylinderSystem untyped), ScAutoRefPtr<T> loses T (mPointee void*), locals not yet applied, x87 compare noise, by-value ScOSIVariant call args garbled.
- SetupBeta.exe (release 1.5.0) = 7z SFX with base64(UTF-16LE) path names; its exe = same build, 798 bytes patched vs repo native/.
- Boxedwine master has a WASM JIT target (Fable 5.1 consult wrongly said none — it read stale docs).
- Fable 5.1 consult effort estimates (UNVERIFIED): viewer 1–2 PM, full decomp port 12–24 PM.
