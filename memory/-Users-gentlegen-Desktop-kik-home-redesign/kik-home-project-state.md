GOTCHA (CSS source order): base `.menu-btn{display:none}` was placed AFTER the `@media(max-width:900px)` block, so equal-specificity later rule won and button never showed at mobile — fixed with `display:flex!important` in the media query, matching the existing `#mobileSearchBtn` pattern. Lesson: this file's responsive show/hide toggles live in an EARLY media block; any later base rule for the same selector needs !important or must precede it.
