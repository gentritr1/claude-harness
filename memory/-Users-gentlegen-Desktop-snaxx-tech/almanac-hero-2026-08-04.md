**v12 SHIPPED (2026-08-06): PING-PONG — the actual answer.** Root cause of every "shake at the loop": drift accumulates MONOTONICALLY through each take (3px @640w by 4s, opposite signs left/right = zoom), so ANY plain cut snaps that offset back at the wrap; no cut point avoids it. Ping-pong (frames 0..N forward, then N-1..1 reverse, endpoints NOT duplicated) makes the wrap structurally impossible to see — every transition is a genuine adjacent-frame pair of untouched footage, measured wrap displacement 0px on all patches vs ±4px for a plain cut. Trade: motion reverses (fine for bobbing/drifting; watch smoke/water). **Reach for ping-pong FIRST on any AI-generated ambient loop — it is the only construction with a mathematical seam guarantee and zero processing artifacts; crossfade/morph/mask all add their own artifact class.** Note SSIM is misleading here (0.93 wrap vs 0.99 adjacent) because both wrap frames are forced I-frames whose independent grain quantization dominates the metric — measure POSITIONAL displacement instead.

**v10 (superseded): CINEMAGRAPH.** User rejected ALL whole-frame motion — and the AI footage's ambient boil covers the entire ground (motion-mask at thr 16 lights up everything incl. title), so no stabilization can fully still it. Solution: frozen base = loop's frame 0 as a literal still; ONLY 10 hand-placed feathered element masks (plane, balloon, chimney smoke, 2 waterfalls, pond, 3 flags, windsock) play video via maskedmerge. Static regions = 0.18 codec dither (perfect stillness); elements live; file 1.8MB. ffmpeg gotchas: still-image inputs into a filtergraph EACH need `-loop 1 -framerate 24 -t <dur>` (a 1-frame mask starves maskedmerge; `-shortest` does NOT stop looped stills feeding a filtergraph → runaway encode; bound with trim=end_frame). Lesson: for 'living illustration' heroes, cinemagraph-from-AI-video should be the DEFAULT architecture, not the fallback — AI i2v global stability can't reach 'static' and viewers anchor on the paper. **v9 scar: the piecewise per-knot stabilization CHASED MEASUREMENT NOISE (±0.5px subpixel matching) and injected a visible breathing/"wind" wobble into footage that was naturally stable — user caught it instantly. Fix: cancel only the least-squares LINEAR TREND (slope through origin) of s/tx/ty — 0.01%/frame, as invisible as the original drift, endpoints still meet. Rule: a stabilizer for *invisible* drift must never correct faster than the drift itself; never feed sub-noise measurements into per-frame corrections.** Generation ends share a systematic regional warp (indie sign −6px, portal +4px vs base) — crossfading two different generations double-exposes signage; morph-through-base avoids it.
