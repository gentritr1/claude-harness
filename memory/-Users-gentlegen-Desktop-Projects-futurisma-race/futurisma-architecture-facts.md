Facts established 2026-08-28 (full code audit + browser playtest):

- The world is a 1D ribbon: ship state is (progress, lateral); `position.y` is assigned from the course sample every physics step (game.ts:1074). No heightfield, no terrain query exists — "drive off the road" is a new spatial system, not a tuning change. Edge clamp lives at game.ts:1098-1156 (edge types A/B hard wall, C = +5.8 m run-off then clamp + auto-recovery).
- Map 02 (Bitterpan) is playable but only reachable via `?map=bitterpan` — no in-game selector. It's a blockout: 0 textures, hardcoded edge "C", no hazards/living-world/lap board, 3 lighting profiles, no env culling.
- Perf headroom is large: measured 92 peak draw calls / ~43k tris / 9.9 ms p95 vs stated ceiling 120 calls / 220k tris (docs/PERFORMANCE_BASELINE.md). Aliveness work has budget.
- Rivals are frozen merged clones of TOTEM (3 liveries, 6 draw calls, no articulation, no shadow blob, no audio). TOTEM itself has 13 animated pivots.
- Audio is 100% procedural WebAudio (no audio files ship); stems crossfade quantized to the bar, one-shots in F minor. No spatial audio anywhere.
- Asset loaders hard-throw on exact counts (60 meshes, 776 tris, 76 relocated hangar components, station_count 610 etc.) — any art re-export breaks load and silently falls back to the 409 KB asset kit. Brittle by design; flag before art iterations.
- HEADLESS SOAKS (the reliable way, added 2026-08-29): append `&headless=1` — public/headless-raf.js (loaded before the game module in index.html) installs a MessageChannel rAF pump and pins document visibility, so soaks run at wall-clock speed with the pane hidden, no incantation needed. Soak = navigate with the FULL flag set `?map=<greenwater|bitterpan>&laps=N&headless=1&diagnostics=1&demo=1` → JS-click #start-button → wait ~200s (GW 5-lap) / ~75s (BP 1-lap) → parse #futurisma-diagnostics JSON (.current). All three flags are load-bearing (burned 6 min on 2026-08-29): without `diagnostics=1` the #futurisma-diagnostics element is never created; without `demo=1` controlMode stays "manual" and the craft sits at 0 km/h forever. BP map code is `bitterpan` (`map02` silently falls back to Greenwater). Lap baseline on this instrument: 34.483/34.433/34.517/34.683/34.683 (docs' 34.500/34.442/... differs by one 60Hz frame on laps 1-2). Never install a rAF shim AFTER page load: the game's pending native rAF wedges forever in an occluded pane and needs one composited frame (tabs_select + screenshot, only works while the pane is displayed) to migrate.
