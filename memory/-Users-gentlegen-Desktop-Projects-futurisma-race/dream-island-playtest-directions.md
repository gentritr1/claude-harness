**Review scar (F-3D water, 2026-09-12):** both water gates PASSED (whitePct 0.5, night p99 184) while the look was destroyed: the sun glint was a two-sine periodic lattice → a white dash grid over a sea that had lost 23 % of its chroma to an uncapped fresnel sky mirror; the wet road became a cyan dot grid. Pattern → a highlight/range gate can be satisfied by tiling white over a surface. Detection rule → every highlight gate ships with a chroma floor on the same band, an aperiodicity check (autocorrelation secondary peak ≤ 0.30 of zero-lag on the white mask), a max-blob size, and a 2× crop for the eyeball. Brief update → written as §8 of DREAM-ISLAND-ALIVE.md; reuse that block for any future "make it sparkle" target.

**Review scars (combined build, 2026-09-12):** (1) The Dream Island soak/capture instruments need the dev server — `__diScene`/`__diCourse` hooks are not present on `vite preview`; a preview soak fails at the material walk. (2) The shipped CSP `style-src 'self'` blocks Vite's injected `<style>` in dev, so any lazy per-circuit stylesheet must be loaded via a `<link>` to a self URL or the dev playtest shows an unstyled HUD. (3) "X contributes to the frame p99" is unreachable when AgX saturates below the frame's existing p99 — compute the tone-curve ceiling before writing a p99-contribution target (fish emissive, F-CODE). (4) Two scripts writing one run.log made a "done" marker match the wrong run; give each run its own log.

**Review scar (vs-design, 2026-09-13) — the night gate I approved in §11 was measuring HUD pixels.** `measure-frames.py`'s default HUD crop drops only the corner bands; the aqua-glass turn cue and world bubble sit inside the world band and are near-white, so "COURT night p99 204 ≥ 150" and "day white 6 %" were both the HUD. World-only (every `#app` child except the canvas hidden, `--full`): day chroma 19.4 / white 0.10 %, night p99 **117** (painting 194). Detection rule → any look gate is captured with the HUD hidden, whole-frame, at a stated chase pose; a gate quoted from an instrument that could include UI pixels is void. The sea shader was NOT the day chroma regression (Codex's pinned-pose sea was bluer than shipped); the white was the additive capsule column over a ~220-luma sky, fixed by drawing it normal-blended by day and additive at night.
