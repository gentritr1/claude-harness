Store signing is LOCAL (user has no EAS): upload keystore `credentials/rowflare-upload.keystore`, alias `rowflare-upload`, credentials in `credentials/keystore.properties` (both gitignored via `/credentials/`, chmod 600). Random 24-char password lives only in that file — user must back the folder up externally; on first Play upload enroll in Play App Signing so this is just the upload key.

Traps:
- `/android` is entirely gitignored and regenerated by `expo prebuild` — a keystore stored inside android/ would be silently deleted, and the hand-edited `signingConfigs.release` block in `android/app/build.gradle` (loads `../credentials/keystore.properties`, falls back to debug when absent) will be LOST on `prebuild --clean` and must be re-applied or moved into a config plugin.
- versionCode is 1 / versionName 1.0.0 in build.gradle (from app.json at prebuild time); bump for every Play update.
