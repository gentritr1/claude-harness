On 2026-08-22 the user said: "make sure overall it is not like a dashboard, but a good polished game." Also: fewer things, better structure, one unified taste; keep the three themes, only polish them; onboarding less wordy and more intuitive; use the Emil Kowalski design-eng rules for motion.

**Why:** The product principle is "make the signal the strongest element" — metric tiles, tables with column headings, analytics copy ("profile", "logged") and reassurance paragraphs all pull attention away from the signal and read as a report.

**How to apply:** No KPI tiles, table headings, or legends anywhere. Numbers live only in the HUD scoreboard (Speed/Accuracy/Streak) and the Score line. Feedback is a *moment* (streak pop, screen tint, NEW BEST tag), not a stat update. Copy is one line per control; guidance lives inside the game surface, not in strips above it. Lab data renders as letter cards with fill bars, not rows. See [[design-pass-2026-08]].
