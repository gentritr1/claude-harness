Source: `~/Downloads/Morse code learning game directions (1).zip` and `(2).zip` — Claude Design canvases (`*.dc.html` + `support.js`), a standalone `Signal Cabin (standalone).html`, and `Signal Cabin - Project Overview.md` (honest gap list). v2 storage key `signalcabin.v2`. Rendered locally by serving the unzipped folder (launch.json entry `directions`, port 4180).

v2 scheduler constants worth porting (from its code, 2026-08-22): `STAB_INTERVALS = [0, 20h, 3d, 7d, 14d, 30d, 60d]`; acquisition needs 2 clean hits ≥ `ACQ_MIN_GAP` 180 s apart and not slow; `SLOW_FACTOR` 1.6 × learner median (baseline 2600 ms until 5 samples); lapse → stab −1 (−2 if lapsed within 3 d), relearn due in 10 min, retry after 3–6 items; clean = not replayed, not interrupted (blur/hidden), rt ≤ 10 s; confusion pairs decay with 7-day half-life minus 0.6 × pair wins, top pair threshold 0.35; backlog brake: pause new letters when overdue ≥ max(4, 30 % known) or > 2 acquiring or clean accuracy(30) < 0.85, resume at ≤ 40 % of that and ≥ 0.88; ranking lanes relearn → due → acquiring → weak/confused → rest, score `0.5 recallRisk + 0.2 lapses + 0.15 slowness + 0.15 confusion`; retention readout r24/r7/r30 from a 400-event log; send judged after `fitUnit` on the learner's own unit, bands clean/developing/readable/rough over last 8.

**v3 (zip (3), "measurement-integrity release") deltas:** fixes its own Farnsworth double-count (ours was always correct — verified PARIS = 60/s) and same-session stability inflation; per-letter medians (≥ 4 own samples) before the per-mode median; lapse decay 14 d; `SHORT_FOLLOWUP` 10 min replaces `RELEARN_GAP`; event cap 4000; v1→v2 storage migration; "held back" reported only when a due review was actually slowed; word practice gated on ≥ 8 usable words, missions on 12; head-copy promotion 4-of-5 across two sessions. Brief 5 ports the v3 rules.

**v4 (zip (4), 2026-08-23) deltas:** interrupted trials are not evidence (separate `exposures`, retry 3–6, nothing else changes); replay-assisted hits are practice (no credit, `lastOk` untouched, retry 4–7); replayed misses still count but do not compound the −2; first session seeded with intro E, intro T, then E T T E before any retrieval; head-copy promotion 3-of-4 within a session in two sessions, decoys matched on Morse sound length (±12 %); stations stabilise only on unaided decodes; honest feedback strings ("with a replay, so it counts as practice"). Ported as brief 5 §13.

**v5 (zip (5), 2026-08-23) deltas — live-round integrity:** `stopAudio()` before any new playback and replay ignored while a signal still sounds (not counted as a replay); send key disabled until the demonstration ends ("Listen first…"); leaving a live round pauses it (timers + audio stopped, "Resume round"); confusion/pair-win writes take the same evidence test as the scheduler (none on interrupted, wins only on clean); load-time normalisers enforce `ok ≤ n`, `exposures ≥ n`; reset stops timers/audio; seed session replaces Arrival and shortens Repair; stations anchor only on unaided decodes; calibration copy now admits placement is not measured. Ported as brief 6.

**v6 (zip (6), 2026-08-23) + "Fix Log" (5 audit rounds):** new for us — skills separated (word/mission answers never reach the character scheduler; per-letter `context {att, elig, ok, indep}`), answers before the final tone rejected (keys at 40 % until signal end), resume without replay when the signal had finished (trial marked interrupted). Fix Log testing note: in a hidden pane/embedded frame `document.hidden` is true so every trial is (correctly) unscored — verify with the pane visible. Ported as brief 6 §8–10.

**v7 (zip (7), 2026-08-23):** measured placement — a same-or-different trial (12 pairs, 3 speeds × 4, pool ETAINMSO, no Morse knowledge needed) picks the fastest character speed with ≥ 75 % accuracy and sets stream spacing from median latency (< 1.4 s → 10, < 2.6 s → 8, else 6 wpm); result persisted with "Measure again"; a visible "Resumed after a pause — this attempt will not count" tag. Closes their #1 known gap (preference calibration). Ported as brief 7 (trial inside our guide step 2 + Settings › Measure, mapping latency onto `effOffset`).

**v8 (zip (8), 2026-08-23):** miss causes — each confusion also records `discrimination` (fast and wrong) / `hesitation` (slow and wrong, > 1.6× baseline) / `uncertain` (replayed and still missed); progress page labels the top pair by cause. Prototype only labels; we port recording AND cause-specific Repair drilling (brief 6 §11).

**v9 (zip (9), 2026-08-23):** evidence-only motivation — returning-visit "Welcome back" summary (what came due, which letters survived a night, latency trend now vs a week ago with a "next target", live pair, fading station, or "nothing is due yet"), session-end "Come back tomorrow for K, M", and one-time milestones (first seven-day interval, first unaided word, first stable station) persisted in `milestones`; every line omitted without enough evidence. Ported as brief 8 (arrival card + milestone tag + come-back line; "next target" number dropped).

**v10 (zip (10), 2026-08-23):** first-contact opener in the seeded session (an unreadable "TE ET" transmission → intro E, intro T → asks → the same transmission read back: "You read it. Two minutes ago that was noise."), plain-language `whyReturning` lines at session end, `stateWord` (new/settle/auto/long/due/relearn) replacing stability numbers in the UI, a dated "radio log" of evidence facts, a persistent station callsign (`KX-412`), evening page tint. Ported as brief 8 §7–10 (opener, callsign in the machine subtitle, one why-line, one dated memory line); stateWord and page tint skipped.

**v11 (zip (11), 2026-08-23):** a 26-entry catalog of "unknown transmissions" (phrases with origin + note, spellable from the frequency-order prefix), one per session in the mission phase when the brake is off and all letters are taught; archived on a clean decode; archive list on the progress page with "N still out there"; faint bandpass static bed (950 Hz, gain 0.012) under all playback; idle lamp breathing; "Station · day N · weather" header. Ported as brief 9 (12-entry catalog for our pool, Use-phase round, drawer archive section, static bed only under transmissions; lamp/day/weather skipped).

**Decisions:** port the scheduler, clean-trial guard, confusion decay, backlog brake, retention-as-words, fitUnit/bands, and auto-adaptive effective speed (widen gaps after 2 missed group rounds, never slow characters). Reject: cream/serif skin (keep the three machines), ETAOIN order (keep Koch-derived), preference-based calibration as the adaptation mechanism, numeric progress readouts, the 20-minute "stable" demo shortcut. Head copy + missions deferred until the alphabet expands.

**How to apply:** Brief 5 = port the above into pure modules (`progress.js`, `performance-profile.js`) with additive, read-migrated fields; see [[design-pass-2026-08]] and [[game-not-dashboard]].
